Relational Integrity & Safety Notice

This application enforces MySQL InnoDB ON DELETE RESTRICT constraints on foreign keys. Residents or visitors who have existing visit logs cannot be deleted to preserve accurate building security audit history. To delete a resident or visitor profile, their linked visit records must be resolved first.

1. Delete Resident Record

Protected Table: residents

Select or enter a resident's ID to delete their account. If this flat has past visitor logs, the system will prevent deletion and display a detailed explanation.

2. Delete Visitor Profile

Protected Table: visitors

Select or search for a registered visitor profile. The database constraint ensures visitors with registered visit entries cannot be deleted accidentally.

3. Delete Specific Visit Record

Parent Table: visits

Individual visit records can be removed by security supervisors if entered erroneously.
